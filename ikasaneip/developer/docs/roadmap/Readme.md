# Ikasan Strategic Roadmap

This document outlines a strategic roadmap for the Ikasan core framework, focusing on improving the reliability and resiliency
of the platform, while creating a suite of productivity tools in order to reduce the cost of adoption and ownership of the Ikasan Platform. 
The roadmap is defined by a number of themes, with the core data model being foundational, while other themes could be developed
in parallel, pivoting off a well defined core data model.
 - [Theme 1: The Ikasan Module JSON Data Model (Foundation)](IkasanDataModel.md)
 - [Theme 2: Module Generation and Migration Upgrade Utilities (Accelerator)](ModuleUpgradeUtilities.md)
 - [Theme 3: The Ikasan IDE (Accelerator)](VisualIDEDevelopment.md)
 - [Theme 4: Configuration Management (Data Management)](GitBackConfigurationManagement.md)
 - [Theme 5: High Availability and Disaster Recovery (Reliability and Resiliency)](HighAvailabilityAndDisasterRecovery.md)
 - [Theme 6: AI-Powered Productivity Tools (Accelerator)](AIPoweredProductivityTools.md)

The central concept is to establish a **standard JSON representation** of an Ikasan module, which will serve as the backbone for all tooling.
